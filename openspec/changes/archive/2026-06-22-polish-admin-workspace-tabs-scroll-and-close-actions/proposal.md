## Why

当前 Admin 桌面多标签已经具备基本的路由驱动、固定总览和单标签关闭能力，但在实际使用里还存在两个不足：

1. 批量关闭入口依赖“更多”溢出菜单，标签刚好放得下时入口消失，不稳定。
2. 标签数量增多后，当前“限制可见数量 + 溢出菜单”的模式不如企业控制台常见的横向滚动模式直观，尤其不利于持续核对多个页面。

本次 change 只打磨桌面 shell 多标签交互，不新增导航层级，不改业务页面，不恢复旧 `/404` 或快捷访问残留标签。

## What Changes

- 桌面端多标签从“固定可见数量 + 溢出更多”改为“固定总览 + 中间横向滚动标签区”。
- `身份总览` 继续作为固定常驻标签，停留在最左侧，不参与滚动，也不可关闭。
- 标签栏右侧新增常驻 `关闭` 菜单，提供 `关闭当前`、`关闭其他`、`关闭所有`。
- 左右滚动箭头仅在对应方向存在可滚动内容时显示。
- 当前激活标签切换时自动滚入可视区，继续保持打开顺序稳定、不重排。
- 移动端仍保持当前降级模式，不在本次 change 内切换到横向滚动标签。

## Capabilities

### Modified Capabilities

- `admin-enterprise-identity-console-shell`: 调整桌面多标签的滚动与关闭管理交互。

## Impact

- 主要影响 `WorkspaceTabs` 组件、标签状态逻辑、`ManagementPage` 接线和少量 shell 样式。
- 不影响后端 API、鉴权、OAuth/OIDC、Gateway、数据库写链路或业务对象语义。
- 需要补充状态逻辑测试、组件交互测试、桌面浏览器验证和 OpenSpec/TS/build 门禁。
