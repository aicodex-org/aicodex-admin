## Context

`GroupListPage.tsx` 已经是 `.tsx` 页面，并通过 `EnterpriseListQueryToolbar` 承载群组页主搜索入口。当前问题集中在表格主体：长 ID 和用户标签直接展开，`编辑` 与禁用 `删除` 在每一行都以高权重按钮出现，`bordered` 表格、固定操作列阴影和表头分割线叠加后让右侧视觉压力过高。

本 change 是 UI polish，不改变 `GroupBackend.getGroups`、`addGroup`、`deleteGroup`、上传接口、下载模板、分页、排序或类型筛选参数。验收反馈将共享“更多筛选”展示纳入当前收口：群组页需要补回真实高级筛选字段，组织页和群组页都应使用工具栏内联展开而不是遮挡正文的浮层。实现必须避让 shell/sidebar/tabs 相关任务。

## Goals / Non-Goals

**Goals:**

- 降低群组列表行操作的重复按钮噪声，保留编辑可达和删除确认/禁用原因。
- 让群组 ID、组织 ID、父级 ID、显示名称和用户列表在表格中更易扫描。
- 降低群组表格固定列阴影、表头网格线、表格边框和排序 tooltip 的压迫感。
- 将群组页和组织页共享“更多筛选”调整为工具栏内部向下展开的搜索区，并让高级筛选字段 label 更像表单字段。
- 用聚焦测试确认查询、筛选、分页、上传、下载、删除禁用和行操作语义不变。

**Non-Goals:**

- 不新增或修改后端 API、数据模型、权限、认证、组织同步或 Gateway 行为。
- 不处理侧栏折叠按钮、标签栏关闭动作、侧栏父子选中态。
- 不重新设计群组详情页、用户页或共享查询工具栏整体结构；只调整群组/组织列表更多筛选的展示方式和字段可读性。
- 不引入新的表格库、全局主题重写或大范围样式重构。

## Decisions

- 使用页面级 `.group-list-table` 类名承载视觉降噪样式。理由：只影响群组列表表格，避免改变组织页、应用页或其它 AntD Table 的既有视觉。
- 长 ID 使用局部渲染器：在单元格内 `ellipsis`/`text-overflow`，同时通过 `Tooltip`、`title` 和链接保留完整信息。替代方案是扩宽列或关闭横向滚动，但会增加首屏负担并影响移动端。
- 用户字段只展示前两个用户标签，超出数量用低权重 `+N` 标签提示，并通过 tooltip 展示完整列表。理由：用户字段是扫描辅助信息，不应把横向宽度推得过大。
- 操作列保留行内直接操作，但把 `编辑` 调整为小号 link button，把 `删除` 调整为小号 text danger button；有子群组时继续 disabled 并保留 tooltip。替代方案是把删除放入更多菜单，但会改变删除入口路径和测试成本，本次先做低风险降权。
- 表格取消 `bordered`，并把 `showSorterTooltip` 限定到 `sorter-icon`。理由：降低表头区域常驻提示与网格线压迫感，同时不移除排序能力。
- “更多筛选”采用工具栏内部内联展开，而不是 Popover。理由：参考图表达的是搜索区向下扩展，内联方式不会遮挡表格，也更符合管理后台批量筛选的可预测性。
- 高级筛选字段 label 统一追加英文冒号 `:`。理由：当前后台双语环境下英文冒号足够稳定，能明确字段和输入框关系，同时避免污染 i18n 文案 key。

## Risks / Trade-offs

- [长字段截断隐藏部分内容] → 通过 tooltip/title 和链接保留完整值，聚焦测试覆盖 class/title 和用户计数。
- [删除按钮降权后不够明显] → 保留 `danger` 语义、文字和图标，并保持删除确认与禁用原因不变。
- [局部 CSS 选择器影响其它表格] → 所有新增表格样式限定在 `.group-list-table` 下，行内类名只由群组页渲染。
- [共享查询工具栏影响组织页] → 仅在存在真实 `advancedFilters` 时渲染展开按钮；组织页聚焦测试和浏览器 smoke 覆盖字段数量、内联容器和冒号。
- [视觉验收依赖真实浏览器] → 自动化先覆盖行为不变量，随后用本地浏览器在 desktop/mobile 视口检查截图、横向溢出和 console/pageerror。
