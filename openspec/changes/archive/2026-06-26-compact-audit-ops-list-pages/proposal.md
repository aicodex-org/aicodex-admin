## Why

审计运维下的登录会话、操作日志、令牌管理和验证码记录页面顶部仍保留大面积工作台卡片，压低了列表首屏可见性；同时搜索、更多筛选、按钮和表格标题还没有完全对齐近期沉淀的统一列表治理壳。

本次变更在不触碰后端契约和公共列表壳全局样式的前提下，移除四个分页列表顶部重复的审计运维摘要块，并让四个列表页复用同一套列表查询、扩展筛选、按钮和表格密度模式。

## What Changes

- 登录会话、操作日志、令牌管理、验证码记录四个分页列表不再渲染审计运维摘要块，首屏直接进入统一列表标题、搜索和表格。
- 登录会话、操作日志、令牌管理、验证码记录四个列表页接入统一列表治理壳：
  - 使用统一列表标题区。
  - 使用统一基础搜索和“更多筛选”入口。
  - 将新增/详情/编辑/删除等按钮对齐到统一列表按钮和行操作样式。
  - 表格分页、表头字体、行高、表头固定和滚动区域跟随现有统一列表页体验。
- 移除这些页面表头内置搜索图标的默认噪声，改由列表工具栏承担查询入口。
- 收敛审计运维表格列宽，避免桌面列表出现横向滚动；令牌授权码、访问令牌和验证码不在列表列中直接展示，仍保留为页面级搜索字段。
- 默认 20 条/页时表格头部和查询工具栏保持在页面上方，滚动发生在表格数据区，避免整页滚动带走头部。
- 操作日志详情抽屉保留右侧查看模式，但内部使用专用滚动容器、轻量摘要区、扁平分区和代码复制按钮；对象载荷跟随抽屉主滚动，避免双滚动和内容较多时无法滚到底。
- 会话列表语义从“会话核对”收敛为“登录会话”，`name` 列显示为“用户”，并补充应用列，使 `组织 / 用户 / 应用 / Session ID` 的会话关系可读。
- 登录会话列表默认仅展示前 2 个 Session ID 和“+N 更多”入口，全部会话 ID 放入右侧抽屉；单个 Session ID 操作表达为“踢出该会话”，行级操作表达为“删除该应用下全部会话”。
- 令牌页保留既有新增、编辑、删除业务行为；操作日志保留详情抽屉；会话页保留删除会话/会话 ID 行为；验证页保留只读表格行为。
