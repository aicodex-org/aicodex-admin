## Context

`GroupEditPage.tsx` 当前是 TSX legacy class component，字段量明显少于组织编辑页。页面只编辑群组元信息：组织、群组标识或同步标识、显示名称、类型、上级组、只读用户标签和启用状态；组织列表中的 `群组` 入口进入的是群组/用户管理视图，不是本编辑页。

组织编辑页已经形成大型编辑页样板，但群组页信息量不足以拆 Tabs。直接照搬 Tabs 会制造空页面和错误成员编辑预期。

## Goals / Non-Goals

**Goals:**

- 让群组编辑页使用单页编辑壳：顶部返回路径、对象标题、未保存状态、正文基础信息区和底部固定操作栏。
- 保持群组元信息编辑紧凑，不全屏拉长输入控件。
- 为群组标识、`显示名称` 增加必填标识和保存前校验。
- 保留现有保存、保存并返回、新增取消删除临时群组、group tree 返回、父级群组和目录同步只读提示语义。
- 将 `用户` 改为只读成员摘要语义，避免误导为成员编辑区。
- 让非目录同步群组可从成员摘要跳转到既有群组树/用户列表上下文维护成员。
- 让工作区顶部标签使用群组对象名区分多个群组页。

**Non-Goals:**

- 不做 Tabs。
- 不在当前编辑页新增群组成员新增、移除、搜索、批量操作或成员编辑能力。
- 不改组织列表中 `群组` 入口、群组树用户列表或 `UserListPage` 的移出群组语义。
- 不新增后端 API，不改变群组保存 payload、删除契约或组织同步/认证/授权链路。

## Decisions

### 单页编辑壳而不是 Tabs

群组页只有一个基础表单区块，拆 Tabs 会降低效率。实现上复用组织编辑页的壳层经验，但不强行复用组织页 Tabs 结构。

页面结构：

- Header：返回按钮、路径、标题、未保存状态。
- Body：一个 `基础信息` 区块，包含全部可编辑群组元信息和只读成员摘要。
- Footer：固定底部操作栏，按钮顺序为 `取消`、`保存`、`保存并返回`。

### 只读成员摘要

`group.users` 继续只读展示。无成员时显示明确空态，例如 `暂无成员`。非目录同步群组提供 `管理成员` 跳转入口，进入既有群组树/用户列表上下文；目录同步群组继续展示只读提示，说明成员由来源系统管理。本 change 不把成员增删能力放入编辑页。

成员摘要优先展示用户 profile 的 `displayName`、`realName`、`name`，查不到 profile 时回退到成员标识的短名。成员数量较多时仅展示前若干个标签，并使用 `+N` 收起剩余成员，避免宽屏和窄屏都被成员标签撑开。

目录同步群组的结构字段来自来源系统。页面将 `名称` 标签切换为 `同步标识`，并禁用同步标识、组织、类型、上级组和成员关系；非目录同步群组将同一字段表达为 `群组标识`，避免与 `显示名称` 混淆。`显示名称` 与 `启用状态` 保持本地可编辑，避免把本系统展示/启用配置误锁死。

### 工作区标签标题

工作区标签先基于 `/groups/:organizationName/:groupName` 或 `/trees/:organizationName/:groupName` 的路径段显示 `群组：<groupName>`，避免多开群组页时全部显示 `群组`。群组详情数据加载后，`GroupEditPage` 通过 shell 内部事件将当前标签更新为 `群组：<displayName>`；该事件只更新已打开标签，不改变路由、持久化格式或后端契约。

### 校验与 dirty 状态

保存前校验 `group.name` 和 `group.displayName` 的 trim 后值。失败时展示字段错误、页面错误提示，并阻止调用 `GroupBackend.updateGroup`。

任意字段变更标记 dirty；保存成功清除 dirty。返回和取消触发 dirty 确认。新增模式取消确认后继续调用 `deleteGroup()`，避免留下预创建群组。

### 样式边界

保留 `group-edit-page` 和 `group-edit-card` 测试/样式定位能力，但可将内部实现从旧 `Card title` 改为页面私有编辑壳。样式使用组织页已沉淀的密度原则和 Admin/AntD token，不引入新色板。

## Risks / Trade-offs

- [Risk] 群组页和组织页壳层相似但不完全一致，后续公共组件抽取可能出现重复。
  - Mitigation: 本次只沉淀稳定命名和样式边界，等第三个编辑页迁移后再抽公共组件。
- [Risk] `用户` 字段改成成员摘要后，用户可能仍期待可编辑成员。
  - Mitigation: 当前页只读展示；本地群组提供到既有群组/用户上下文的跳转，目录同步群组明确由来源系统维护。
- [Risk] 新增 dirty 确认可能影响新增取消清理。
  - Mitigation: 新增模式取消确认后仍走既有 `deleteGroup()`，测试覆盖 group tree URL 返回。
